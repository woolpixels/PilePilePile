# 堆堆堆 PilePilePile

一个可直接使用的本地优先文字构图工具，将输入的词条自动排布成指定形状，并可继续调整字号、颜色、旋转、间距和背景。默认输出画布为 1080 × 1080 px，支持 PNG、SVG 导出及复制 SVG。

*PilePilePile arranges words into editable typographic shapes for posters, graphics, and visual storytelling.*

## 本地运行

无需安装依赖：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

## 当前能力

- 中文/英文词语解析，支持空格、换行、顿号、逗号、分号
- 自定义最小字号、档位数和档位跨度
- 默认使用苹方，预置中文无衬线/衬线与英文无衬线/衬线各一款：苹方、华文宋体、Helvetica Neue、Georgia
- 文字默认不旋转，支持随机角度和10种可多选的自定义角度
- 正方形、长方形、圆形、星形、心形、云朵和微博图形
- 节点绘制自定义形状
- 上传图片生成遮罩，并支持反转明暗区域
- 预置配色和自定义 HEX 色值
- 默认使用鲜果配色，预置鲜果、晴日、紫霞、海岸、森林、日落和墨彩等方案
- 界面品牌色采用橘色，覆盖主按钮、常规控件选中态和节点绘图反馈；词条选中框使用蓝色编辑描边
- 进度条使用浅灰轨道与橘色进度；形状选择采用无文字的居中方形图标卡
- 节点绘图支持闭合、撤销和重绘
- 预置形状、节点图形和图片遮罩可作为独立背景层显示，并可调整颜色与透明度
- PNG、SVG 导出和复制 SVG
- SVG 使用显式字形基线偏移，提升粘贴到设计软件后的文字位置一致性
- 复制 SVG 直接输出文字节点，不再为每个词条创建独立分组，减少设计软件中的文件夹层级
- 单击画布词条可进一步设置字号档位和颜色；选中时显示类似设计软件的元素描边框
- 词条颜色可选择跟随当前排版，或固定使用当前配色中的指定颜色
- 词条设置弹窗会直接选中当前字号档位和颜色；点击“保存”固定设置，点击“恢复默认”立即取消该词条的独立设置
- 画布下方提供默认收起的词条详情列表，可查看并修改每个词条的字号档位和颜色；开启循环填充后额外显示出现数量
- 支持全局撤销和重做，覆盖文字、字号、间距、配色、形状、旋转、背景、词条设置、随机字号和重新排版等操作
- 支持 `Command + Z` 与 `Command + Shift + Z`；连续输入和滑杆拖动会合并为一条历史，最多保存 50 条
- 导出和复制不写入操作历史，编辑选中框也不会出现在导出结果中
- 透明背景、文字间距、旋转角度、目标文字数
- 根据词语总面积自动生成紧凑形状，少量词语不会被强行摊满画布
- 排版以“不缺字”为硬约束；常规档位无法容纳全部词条时会继续缩小字号，并在极端情况下使用最小字号紧凑放置
- 默认按输入文字与形状面积自动缩放整组字号档位，最大字号支持 260 px
- 上传 SVG、图片遮罩及节点绘图会按真实形状面积和边界自动适配字号
- “随机字号”会生成新的档位数、跨度与填充强度；“重新排版”按当前固定参数更换排版；两者都会清除词条独立设置，并可通过撤销恢复
- 关闭自动字号后，可逐项编辑每个字号档位
- 支持上传并在浏览器本地保存 SVG 预置形状

## 文件结构

- `index.html`：界面结构
- `styles.css`：视觉样式
- `app.js`：词语解析、排版、绘制和导出逻辑
